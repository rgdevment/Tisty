# Atajos de teclado

Toda la ventana funciona con el teclado.

| Atajo | Qué hace |
| :-- | :-- |
| `Ctrl` + `Shift` + `Space` | Capturar una tarea desde cualquier parte, sin abrir la ventana |
| `Enter` (en la captura rápida) | Guardar la tarea |
| `Ctrl` + `Alt` + `I` (si lo eliges en **Configuración › Tareas y avisos**) | Anotar una idea para [Ideas](Documentos#ideas) desde cualquier parte |
| `Tab` (en la captura rápida) | Cambiar entre una tarea, una idea para [Ideas](Documentos#ideas) y hoy en el [Diario](Documentos#diario); `Shift` + `Tab` vuelve atrás |
| `Ctrl`/`⌘` + `Enter` | Sobre la fila de una tarea en la lista, terminarla; escribiendo en un documento o en la página de una tarea, un salto de página |
| `Ctrl`/`⌘` + `Enter` (en el cuadro del Diario) | Guardar lo que escribiste en hoy |
| `/` | Insertar algo dentro de un documento |
| `Shift` + `Enter` (escribiendo un documento) | Saltar de línea sin empezar un párrafo |
| `Ctrl`/`⌘` + `/` (escribiendo un documento) | Abrir el menú de bloques donde está el cursor |
| `Alt` + ↑ ↓ (escribiendo un documento) | Subir o bajar el bloque o el elemento donde está el cursor; en una tarea, sin salir de su sección |
| `Esc` · `Shift` + ↑ ↓ (escribiendo un documento) | Elegir el bloque entero, o en una lista el elemento y con otro `Esc` la lista entera · sumar los de al lado |
| `Ctrl`/`⌘` + `B` · `I` · `U` (escribiendo un documento) | Negrita · cursiva · subrayado |
| `Ctrl`/`⌘` + `Shift` + `X` · `Shift` + `C` (escribiendo un documento) | Tachado · código |
| `Ctrl`/`⌘` + `K` (escribiendo un documento) | Poner un enlace, o cambiar la dirección de uno ya escrito |
| `Ctrl`/`⌘` + clic en un enlace (escribiendo un documento) | Abrir el enlace; un clic solo pone el cursor en sus palabras |
| `Ctrl`/`⌘` + `Z` · `Ctrl`/`⌘` + `Shift` + `Z` o `Ctrl`/`⌘` + `Y` (escribiendo un documento) | Deshacer · rehacer |
| `Ctrl`/`⌘` + `C` · `X` (escribiendo un documento) | Copiar · cortar como Markdown las palabras o los bloques elegidos |
| `Tab` · `Shift` + `Tab` (escribiendo una lista) | Meter un elemento bajo el de arriba o sacarlo |
| `Ctrl`/`⌘` + `E` (en un documento) | Cambiar entre Enriquecido y Markdown |
| `F1` | Abrir la guía de Markdown de Tisty, sin conexión |
| `Ctrl`/`⌘` + `P` | Abrir la [paleta](#la-paleta) para saltar a un documento, una tarea o una carpeta |
| `Ctrl`/`⌘` + `Shift` + `P` | Abrir la [paleta](#la-paleta) en sus acciones |
| `Ctrl`/`⌘` + `K` (fuera de lo que escribes) | Ir al buscador de arriba de la barra lateral, desplegándola antes si está plegada |
| `Ctrl`/`⌘` + `B` (fuera de lo que escribes) | Plegar la barra lateral a sus iconos, o desplegarla; arrastra su borde para cambiar el ancho. Cuando la columna de la derecha no cabe a su lado, la barra lateral se pliega sola a sus iconos; si la abres a mano, queda abierta hasta que cambias de vista o de tamaño de ventana |
| `Ctrl`/`⌘` + `S` (en la ventana de diagramas) | Guardar el diagrama en su documento |
| `Enter` · `Tab` · `Supr` · `F2` (en un mapa mental) | Agregar una hermana, agregar una hija, borrar la idea, renombrarla |
| `Supr` (en un esquema, un diagrama libre o un diagrama de clases) | Borrar lo elegido |
| `Ctrl`/`⌘` + `Z` · `Ctrl`/`⌘` + `Shift` + `Z` o `Ctrl`/`⌘` + `Y` (en la ventana de diagramas) | Deshacer y rehacer lo que cambió la ventana |
| `Ctrl`/`⌘` + `D` (en un diagrama libre) | Duplicar la forma elegida |
| `Ctrl`/`⌘` + clic · `Shift` + arrastrar (en la ventana de diagramas) | Elegir varias formas, clases o tablas |
| `Ctrl`/`⌘` + `X` · `V` (sobre un documento en la Biblioteca) | Mover un documento entre carpetas |
| `Alt` + flecha (sobre la fila de una página) | Subir o bajar una página dentro de su documento |
| `Alt` + flecha (en una tabla: ↑ ↓ con una celda abierta, y las cuatro en la vista Markdown) | Mover la fila o la columna donde está el cursor; `Ctrl` + `Alt` + ← → en un Mac |
| `Esc` | Cerrar lo que esté abierto; escribiendo un documento, elegir el bloque |

Si otro programa ya usa el atajo de captura, Tisty toma otro y te dice cuál en **Configuración › Tareas y avisos**.

## En Configuración

| Atajo | Qué hace |
| :-- | :-- |
| `↑` `↓` (en la columna) | Mover el foco entre las páginas, sin abrirlas |
| `Enter` (en la columna) | Abrir la página marcada |
| `←` `→` (en las pestañas de **Asistentes**) | Cambiar de pestaña |
| `Inicio` / `Fin` (en la columna o en las pestañas) | Ir a la primera o a la última |
| `Esc` | Salir de Configuración; en **Buscar un ajuste**, primero borra lo que escribiste |

Más en [Configuración](Configuración#abrir-la-configuración).

## La paleta

`Ctrl`/`⌘` + `P` abre un cuadro arriba de la ventana. Escribe parte de un título y salta: primero van los documentos cuyo título coincide, después las carpetas, las tareas, también las del archivo, y los documentos que dicen esas palabras en el texto. Sin escribir nada, muestra los documentos que escribiste hace poco. ↑ ↓ eligen, `Enter` abre y `Esc` cierra.

Si empiezas con `>`, la paleta muestra las acciones de la ventana: ir a una vista, crear un documento o una carpeta, plegar la barra lateral y, con un documento abierto, cambiarlo entre Enriquecido y Markdown o exportarlo. Cada acción muestra su atajo, si lo tiene. `Ctrl`/`⌘` + `Shift` + `P` abre la paleta con el `>` ya puesto.

## En el visor liviano

Un [archivo abierto desde afuera](Documentos#abrir-un-archivo-markdown-de-afuera) tiene sus propias teclas:

| Atajo | Qué hace |
| :-- | :-- |
| `Ctrl`/`⌘` + `F` | Buscar en el texto |
| `Ctrl`/`⌘` + `\` | Abrir o cerrar la columna junto a la página |
| `Ctrl`/`⌘` + `Shift` + `M` | Cambiar entre la página y su Markdown |
| `Ctrl`/`⌘` + `Shift` + `L` | Cambiar el tema |
| `Ctrl`/`⌘` + `=` · `-` · `0` | Texto más grande, más pequeño, tamaño normal |
| `Alt` + ↑ ↓ | Ir al título anterior o al siguiente |
| `Alt` + ← | Volver después de seguir un enlace |
| `Ctrl`/`⌘` + `P` | Imprimir |
| `Ctrl`/`⌘` + `W` | Cerrar la ventana |
| `Esc` | Cerrar el menú, la búsqueda, el Markdown o la columna |
