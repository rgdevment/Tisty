# Keyboard shortcuts

The whole window works from the keyboard.

| Shortcut | What it does |
| :-- | :-- |
| `Ctrl` + `Shift` + `Space` | Capture a task from anywhere, without opening the window |
| `Enter` (in the quick capture) | File the task |
| `Ctrl`/`⌘` + `Enter` | Complete the task you are on; in a document you are writing, a page break |
| `/` | Insert something inside a document |
| `Shift` + `Enter` (writing a block) | Break the line without starting a paragraph |
| `Ctrl`/`⌘` + `Shift` + `M` (writing a block) | Show or hide every mark |
| `Ctrl`/`⌘` + `E` (in a document) | Open or leave the whole document |
| `F1` | Open the Tisty Markdown guide, without a connection |
| `Ctrl`/`⌘` + `B` (outside what you are writing) | Fold the sidebar to its icons, or unfold it; drag its edge to change its width |
| `Ctrl`/`⌘` + `S` (in the diagram window) | Save the diagram into its document |
| `Enter` · `Tab` · `Delete` · `F2` (in a mind map) | Add a sibling, add a child, remove the idea, rename it |
| `Delete` (on a schema, freeform diagram or class diagram) | Remove what is chosen |
| `Ctrl`/`⌘` + `Z` · `Ctrl`/`⌘` + `Shift` + `Z` or `Ctrl`/`⌘` + `Y` (in the diagram window) | Undo and redo what the window changed |
| `Ctrl`/`⌘` + `D` (in a freeform diagram) | Duplicate the chosen shape |
| `Ctrl`/`⌘` + click · `Shift` + drag (in the diagram window) | Choose several shapes, classes or tables |
| `Ctrl`/`⌘` + `X` · `V` | Move a document between folders |
| `Alt` + arrow (on a page's row) | Move a page up or down in its document |
| `Alt` + arrow (in a table, writing its text) | Move the row or the column the caret is on; `Ctrl` + `Alt` + ← → on a Mac |
| `Esc` | Close whatever is open |

If another program already holds the capture shortcut, Tisty takes another one and tells you which in Settings.

## In the light viewer

A [file opened from outside](Documents#opening-a-markdown-file-from-outside) has keys of its own:

| Shortcut | What it does |
| :-- | :-- |
| `Ctrl`/`⌘` + `F` | Find in the text |
| `Ctrl`/`⌘` + `\` | Open or close the column beside the page |
| `Ctrl`/`⌘` + `Shift` + `M` | Switch between the page and its Markdown |
| `Ctrl`/`⌘` + `Shift` + `L` | Change the theme |
| `Ctrl`/`⌘` + `=` · `-` · `0` | Larger text, smaller text, normal size |
| `Alt` + ↑ ↓ | Go to the previous or the next heading |
| `Alt` + ← | Go back after following a link |
| `Ctrl`/`⌘` + `P` | Print |
| `Ctrl`/`⌘` + `W` | Close the window |
| `Esc` | Close the menu, the search, the Markdown or the column |
