# Rina

This sheet is a page of the guide. It is not here to tell you anything about Tisty: it is here so you can see from the inside what the section before it described.

![Rina on her chair](rina.jpg)

Notice three things you can only see from within one.

At the top you have which document this page belongs to and where it sits in it, with arrows to its sisters if it had any. It is a document like any other — the same file on disk, the same output when exported — and the only thing that sets it apart is that line: it says whose it is.

In the guide's text, this sheet is not stuck at the end. It is named exactly where naming it made sense, and that is where it goes. Move that block somewhere else and the page moves with it: in the tree, when printing and when exporting.

And the photograph above travels with the document. It is not a link to a folder on your disk that breaks the day you move the file: the picture is kept inside Tisty, and it comes out with the page when you export it.

> [!TIP]
> Try deleting the line that names this page in the guide. The page does not disappear: it loses its place in the text and drops to the contents at the end, waiting for you to put it back wherever you want it.
